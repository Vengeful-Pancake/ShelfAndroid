# Shelf 0.3.5

- Hiện phiên bản ngay trên màn hình Books. Chạm vào phiên bản, hoặc mở menu → Phiên bản và cập nhật để xem mã build, release/debug, nguồn, lần kiểm tra gần nhất và lỗi.
- Sửa tình trạng không hiện thông báo khi GitHub giới hạn REST API: đọc metadata từ file release public `update.json` trước; chỉ dùng API cho release cũ chưa có metadata này.
- Kiểm tra ngay khi khởi động tiến trình mới và khi quay lại app, mỗi 15 phút nếu tiếp tục dùng. Bỏ khóa chờ 6 giờ bị giữ từ bản cũ; lỗi mạng thử lại sau 1 phút hoặc đúng thời gian GitHub yêu cầu.
- Nút kiểm tra thủ công có tiến trình và kết quả rõ ràng; không làm mất yêu cầu khi phần giao diện cập nhật chưa sẵn sàng. Lỗi kiểm tra được lưu để xem lại, không bị hiểu nhầm là đã dùng bản mới nhất.
- Release được tải đủ APK, SHA-256, source ZIP và update.json ở trạng thái draft rồi mới công bố, tránh nhận release chưa tải xong APK.
- Giữ kiểm tra mã ứng dụng, SHA-256, kích thước, versionName, versionCode tăng và cùng chứng chỉ ký trước khi mở trình cài Android.

Nếu bản đang dùng không tìm thấy cập nhật, tải APK này và cài đè một lần. Không gỡ app để giữ dữ liệu. Android vẫn yêu cầu xác nhận cài đặt.
