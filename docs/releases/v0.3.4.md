# Shelf 0.3.4

## Browser

- Multiple browser tabs: open, switch and close tabs from the tab counter. Long-press a link or follow a user-opened new-window link to open a new tab.
- Keep up to 20 open tab URLs, titles and scroll positions locally across restarts. Recent pages stay live; older pages can reload to limit memory use.
- Search browsing history (latest 1,000 visits), open entries in the current/new tab, remove individual entries or clear history.
- Add/remove favorites with the star. Search and open saved favorites from the browser menu.
- Extensions panel: enable/disable the built-in Smooth Xianxia / QT extension. Turning it off restores original Chinese text; late translation responses are ignored. Reader translation settings stay separate.

## Bottom navigation

- Open the gear beside Books / Internet / Dictionary, or Browser menu → Navigation bar.
- Adjust size from 65% to 140%, or hide/show the bar. A small bottom arrow brings it back when hidden.
- Remember navigation/extension preferences and include them in reading-settings backups.

Install over the current version to keep existing books, Names and reading positions. Check for updates in the app to download the signed APK.
